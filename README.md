## 📌 Project Overview

Customer churn is one of the costliest problems in telecom. This project turns raw customer data into a **business-ready churn and revenue-risk analysis**, covering the full pipeline: data cleaning, SQL-based business analysis, churn KPI calculation, revenue-loss analysis, customer segmentation, dashboard visualization, and actionable recommendations.

The analysis was built to answer one core question for the business: **who is churning, why, and how much is it costing us?**

<div align="center">

| 📉 Overall Churn Rate | 💸 Revenue Lost | 📊 Revenue Loss % |
|:---:|:---:|:---:|
| **50.84%** | **$3,684,459.82** | **35.34%** |

</div>

> 💡 **Why this project matters:** It doesn't stop at "churn rate is X%." Every finding here is tied to a revenue number and a specific customer segment — the kind of analysis a retention or CX team could act on directly.

## 🔄 Project Workflow

### 1️⃣ Data Cleaning — *Python*
- Cleaned and standardized the raw telecom customer dataset
- Handled missing values, inconsistent categories, and data types
- Engineered churn and revenue-loss flags for downstream analysis
- Exported the cleaned dataset for SQL and Tableau

### 2️⃣ SQL Analysis — *MySQL*
Queried the cleaned dataset to evaluate:
- Churn rate by contract type, internet type, age group, and satisfaction score
- Top churn categories and churn reasons
- Total revenue, revenue lost, and revenue loss percentage
- Revenue loss by churn category and by payment method
- High-risk, high-revenue customer segments
- High-CLTV churned customers for win-back targeting

### 3️⃣ Dashboard Design — *Tableau*
Built two focused dashboards covering churn behavior and financial impact (see below).

## 💡 Business Recommendations

1. **Incentivize contract upgrades** — encourage Month-to-Month customers to move to One Year or Two Year contracts using loyalty discounts, bundled plans, or long-term value offers.
2. **Target low-satisfaction customers early** — proactive support and retention offers before they churn.
3. **Improve Fiber Optic customer experience** — review pricing, reliability, speed expectations, and support quality.
4. **Respond to competitor pressure** — benchmark competitor pricing, device offers, and promotions.
5. **Review payment-method risk** — investigate billing friction for higher-risk payment groups.
6. **Prioritize high-risk, high-revenue segments** — focus retention campaigns where churn rate *and* revenue loss are both high.
7. **Build a win-back strategy for high-CLTV churned customers** — target high-value churned customers with personalized offers.

## ▶️ How to Run This Project

**1. Clone the repository**
```bash
git clone https://github.com/aditya-pandey-data/telco-customer-churn-analysis.git
cd telco-customer-churn-analysis
```

**2. Install dependencies and run the cleaning notebook**
```bash
pip install -r requirements.txt
jupyter notebook notebooks/data_cleaning.ipynb
```

**3. Run the SQL analysis**

Import the cleaned dataset into your SQL database, then run:
```sql
SOURCE sql/churn_analysis.sql;
```

**4. Open the Tableau dashboard**
```text
tableau/telco_churn_dashboard.twb
```
If Tableau asks for the data source, reconnect it to:
```text
data/cleaned_telco_churn.csv
```
